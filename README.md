# Pemesanan Tiket

Aplikasi sederhana untuk memesan tiket dengan fitur pengaturan jumlah tiket dan perhitungan total harga otomatis. Dibuat sebagai tugas Pengembangan Aplikasi Mobile.

## Fitur
- Menampilkan harga tiket per unit
- Tombol tambah (+) dan kurang (−) untuk mengatur jumlah tiket
- Jumlah tiket tidak bisa kurang dari 1
- Perhitungan total harga otomatis (harga tiket × jumlah tiket)
- Tombol reset untuk mengembalikan jumlah dan total ke kondisi awal
- Format harga menggunakan format Rupiah (Rp25.000)

## Teknologi yang Digunakan
- Bahasa: Kotlin
- IDE: Android Studio
- Library: AndroidX AppCompat, ConstraintLayout, CardView
